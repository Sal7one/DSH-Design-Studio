# Repo-local agent skills

These skills are part of the repository, not the DSH profile. They are not
automatically guaranteed to be discovered by DSH or other agent runtimes.
Follow the host's skill-loading instructions if a user wants to enable one;
do not install or enable skills globally without an explicit request.

- `design-studio/` — build, edit, preview, style, snapshot, and review Design
  Studio mockups. See also `docs/design-studio-handbook.md`.

- `qalens-integration/` — help a consenting Android team evaluate or integrate
  the optional QaLens SDK and connect its workbench to Design Studio. This is
  not required for web mockups or other app targets. See
  `docs/QALENS_INTEGRATION.md`.
