# Repo-local agent skills

These skills are part of the repository, not the DSH profile. They are not
auto-discovered by DSH yet; copy/symlink a skill folder into the profile's skill
location when you want the host to load it.

- `design-studio/` — build, edit, preview, style, snapshot, and review Design
  Studio mockups. See also `docs/design-studio-handbook.md`.
