    Design notes & reusable components

    Direction. Charcoal/navy surfaces with one electric-blue accent; severity/status colors are semantic and never the only signal (every badge carries an icon or text label). No gradients or stock imagery — hierarchy comes from type, borders, and density.

    Reusable components. KpiCard, Sparkline, AreaChart (with hover tooltip), MiniBars, IncidentTable (with loading / empty / error states), IncidentRow, SeverityBadge, StatusPill, Avatar, Timeline, ServiceCard, Drawer, Modal, ChipGroup, Toast. All mock data is labeled demo data and lives in js/app.js.

    Demo states. Use the switches in the table header ("Simulate loading / error") to see the loading skeleton, the empty state (pick filters with no matches), and the error state with retry.
