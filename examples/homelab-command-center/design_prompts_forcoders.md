# design_prompts_forcoders — homelab-command-center

Source of truth for this design: /user_need.md (the homelab custom dashboard spec).
Data source for the service grid: /ops/service-index.json (generated by /scripts/gen-service-index.py).

## What this screen is

The dashboard HOME screen. It answers "is anything blocked, stuck, failing, or waiting on me — and is
anything ready to ship?" in under five seconds. It is a READ-ONLY projection of the homelab: it never
mutates state and never issues a verdict (user_need.md section 3).

## Layout (top to bottom)

1. Top bar — title, live health dots (harness3 / harness2 / goodbot / swarm-kernel / forge), clock, "updated Ns ago".
2. KPI row — 4 cards: active runs, services up/down, pending decisions, open alerts. Calm until a number is bad.
3. "Needs you now" rail — the loudest zone on screen; every item awaiting an operator decision.
4. Spend / cutover strip — running spend (per run and per hour) + the H2-to-H3 cutover gate progress.
5. Service grid — one row per service (status, host port, hostname, profile), sourced from ops/service-index.json.
6. Activity timeline — recent run / deploy / backup / alert events (quiet ambient ticker).

- harness3  GET :8797/health  +  /api/operator/runs  +  /api/operator/model
- GoodBot   GET :8790/health  +  WA bridge :3100/health  (paired vs QR-needed)

## Non-negotiables (from user_need.md section 3)

- Read-only; no client-side authority (harness3 Spine rule).
- Honest empty states; never a fabricated number.
- Never render secret VALUES (env var names only).
- Consolidate (this replaces Homepage, deep-links to dockge/dozzle/uptime-kuma/cockpit/goodbot-gui).
- Respect hardware: 16 GB, one gradle build, one phone, the Mac sleeps, LAN DNS has no wildcards.

## Design language

Dark theme (TV-friendly), large type, dense but breathable. KPI cards are calm; only the offending number
turns warn/err. "Needs you now" is the loudest visual. The "all clear" state ("Nothing needs you. N builds
running clean.") is a feature, not an empty state. Timeline is a quiet ticker, not a focal point.
